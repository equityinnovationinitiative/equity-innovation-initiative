This folder is a static website. No hosting or domain has been activated.

FAST FREE DEPLOY (GitHub Pages)
1. Create a GitHub account or sign in at https://github.com/
2. Create a PUBLIC repository, e.g. equity-innovation-initiative-site.
3. Upload the CONTENTS of this folder to the repository root (index.html must be at root).
4. Open Settings > Pages > Build and deployment > Deploy from a branch.
5. Select main and /(root), then Save.
6. Wait for GitHub Pages to display the URL and open it.
7. Test the demo, documentation links and phone layout.
8. Share the resulting URL for review before buying a custom domain.
